# Отдел Farm — сайт учёта

Сайт вместо Google-таблицы: состав отдела, оплаты, отпуска, штрафы и отчёт по неделям.
Вход через Discord, доступ выдаёт руководство.

## Что считается само

- **Дни по сумме оплаты** — по таблице цен (1 день — 15 000$, …, 7+ дней — 7 500$/день).
  Остаток, которого не хватает на целый день, не переносится: 125 000$ → 16 дней.
- **Вступительный взнос** (5 000$) — галочка в форме оплаты; у новичка без оплат она ставится сама.
- **Дата следующей оплаты.** Если человек платит заранее, дни добавляются к концу текущего срока.
  Если с опозданием — срок идёт от даты оплаты. Отпуск сдвигает дату на число дней отпуска.
- **Статус**: Оплачено (сколько дней осталось) / Сегодня оплата / Требуется оплата (сколько дней просрочки) / Не в отделе.
- **Не платит взнос** — галочка у участника (например, старший состав): «Оплачено до ∞», автоштрафов нет.
  Должность (Участник, Cur. Farm, D.Head Farm, Head Farm) от оплаты сама не освобождает.
- **Сколько внести должнику** — самая дешёвая оплата, закрывающая долг по сегодня включительно.
- **Штрафы** выдаются по пунктам правил. Санкция — набор плашек (сумма, штрафной ранг, исключение, ЧС,
  свой текст); если вариантов несколько («50 000$ или ЧС»), при выдаче выбирается один. Плашки «ЧС» и
  «Исключение» сразу заносят в чёрный список и ставят дату увольнения. Срок оплаты — 3 суток, потом «Просрочен».
- **Автоштраф** — у пункта правил можно указать «через N дней неоплаты взноса» (для 1.1 — 2 дня):
  штраф выдаётся сам, один раз на каждую просрочку. «Сегодня» считается по московскому времени.
- **Сколько дней в отделе**, **внесено за неделю** (пн–вс) и за всё время.
- **Напоминание должникам** — показывает должников и готовый текст для Discord: упоминание, с какого числа
  не оплачено, сколько внести и санкция за неуплату из правил.

## Правила и чёрный список

- Правила (категории, пункты, плашки санкций, примечания, срок оплаты штрафа) меняет администратор
  на вкладке «Цены и правила».
- Чёрный список — отдельная вкладка. Если добавить в состав человека с Discord ID из ЧС, сайт предупредит.
- Журнал действий владелец может чистить: по одной записи, всё старше 30 дней или целиком.

## Бот: теги Discord

По Discord ID участника сайт сам узнаёт его тег (`@username`), отображаемое имя и аватар.
Это делает бот того же Discord-приложения, через которое работает вход. **Приглашать бота на ваш
сервер Discord не нужно**: Discord отдаёт эти данные по ID любого пользователя.

- Тег подтягивается сразу после добавления участника или смены его ID.
- Раз в сутки теги сверяются заново: люди меняют ники.
- В форме участника, пока вводите ID, видно, кто это (`✓ @tag`), — так легко поймать ошибку в ID.
- Если ID не существует, участник помечается «ID не найден в Discord».
- В карточке участника есть кнопка «Обновить тег».

Нужен только `DISCORD_BOT_TOKEN` (см. ниже). Без него сайт работает, просто без тегов.

## Уровни доступа

| Уровень | Что может |
|---|---|
| Участник отдела | Выдаётся сам, если Discord ID человека есть в составе. Видит только свою карточку. |
| Просмотр | Видит все данные. |
| Редактор | Вносит оплаты, отпуска, штрафы, ЧС, меняет состав. |
| Администратор | Плюс цены, правила, выдача доступа и журнал действий. |
| Владелец | Задаётся переменной `OWNER_DISCORD_IDS`. Назначает администраторов и чистит журнал. |

Кто вошёл через Discord без доступа, появляется на вкладке «Доступ» в разделе «Запросы доступа» —
доступ выдаётся одной кнопкой.

## Запуск

Нужен Node.js 20 или новее. База данных — SQLite, файл `data/farm.db`: на Node 22.13+ используется
встроенный модуль, на Node 20 — пакет `better-sqlite3`, который ставит `npm install`.
Какой вариант выбран, видно в первой строке журнала при запуске.

### 1. Приложение в Discord

1. Откройте https://discord.com/developers/applications → **New Application**, назовите, например, «Farm Otdel».
2. Слева **OAuth2**. Скопируйте **Client ID**, нажмите **Reset Secret** и скопируйте **Client Secret**.
3. Там же в **Redirects** добавьте адрес `<BASE_URL>/auth/discord/callback`,
   например `http://localhost:3000/auth/discord/callback` для проверки на своём компьютере.
4. Слева **Bot** → **Reset Token** → скопируйте токен (это `DISCORD_BOT_TOKEN`).
   Там же можно выключить **Public Bot**, чтобы никто не мог добавить бота к себе.
   Никакие Intents и приглашение бота на сервер не нужны.

### 2. Файл `.env`

```
BASE_URL=http://localhost:3000
DISCORD_CLIENT_ID=...         # из шага 1
DISCORD_CLIENT_SECRET=...     # из шага 1, никому не показывайте
DISCORD_BOT_TOKEN=...         # из шага 1, никому не показывайте
OWNER_DISCORD_IDS=...         # ваш Discord ID: правый клик по себе → «Копировать ID»
```

«Копировать ID» появляется после включения: Настройки Discord → Расширенные → Режим разработчика.

### 3. Старт

```bash
npm install
npm start
```

Сайт откроется на `http://localhost:3000`.

`DEV_LOGIN=1` включает тестовый вход без Discord (работает, только когда `BASE_URL` — localhost).

## Запуск на Bothost

Сайт работает как обычный Node.js-бот Bothost из репозитория GitHub.

1. **Код.** Загрузите в репозиторий всё содержимое папки, кроме `node_modules`, `data` и `.env`.
   Bothost сам выполнит `npm install` и запустит `index.js`.
2. **Переменные окружения** (в настройках бота на Bothost, их не больше пяти):

   | Переменная | Что это |
   |---|---|
   | `DISCORD_CLIENT_ID` | Developer Portal → OAuth2 → Client ID |
   | `DISCORD_CLIENT_SECRET` | Developer Portal → OAuth2 → Client Secret |
   | `DISCORD_BOT_TOKEN` | Developer Portal → Bot → Token (для тегов) |
   | `OWNER_DISCORD_IDS` | ваш Discord ID |

   Адрес сайта задавать не нужно: сервер берёт его из запроса. Пятая переменная остаётся свободной.
3. **Discord Developer Portal → OAuth2 → Redirects**: добавьте адрес
   `https://<домен бота на Bothost>/auth/discord/callback`. Если вход не проходит,
   на странице входа будет показан точный адрес, который ждёт Discord.
4. **Перезапустите бота.** В журнале должна появиться строка вида
   `Farm Otdel: … база better-sqlite3: /app/data/farm.db`.

База хранится в `/app/data` — это постоянный диск Bothost, она переживает перезапуски
и обновления из GitHub. Копию базы можно скачать во встроенном файловом менеджере Bothost.
